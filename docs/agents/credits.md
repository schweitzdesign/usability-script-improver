# Credits

## Product Manager Skills (Dean Peters)

The PM bot's instructions ([`ops/hermes/pm/SOUL.md`](../../ops/hermes/pm/SOUL.md)) borrow
ideas from the open
[Product-Manager-Skills](https://github.com/deanpeters/Product-Manager-Skills) library by
Dean Peters, which is licensed
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

What we took, as ideas only:

- **Incoming request advisor:** separate the literal ask from the underlying job, and write
  the problem as the job and the obstacle rather than as the requested fix.
- **User story:** a specific persona, "as a / I want / so that", written about the person
  rather than the interface.
- **Prioritization advisor:** pick a scoring framework that fits the situation and say why
  (here ICE, because Confidence is explicit and thin evidence honestly lowers the rank).
- **Feature investment advisor:** recommend build, defer, or drop, with the reasoning and the
  cost of doing nothing.

The instructions are written from scratch for POKE. No text from the library is copied into
this repository, and none of its files are committed here. Because the library is licensed
for non-commercial use with share-alike terms, treat the PM instructions as a derivative of
those ideas: credit stays with this file, and any reuse should stay non-commercial and carry
the same license. This project is a course capstone and not commercial.
